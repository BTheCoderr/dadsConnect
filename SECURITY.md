# Security Policy

Security fixes target the current default branch.

Report vulnerabilities privately through GitHub when they could expose accounts, family/location context, private messages, meetup data, saved content, Supabase credentials, or RLS-protected records.

Extra review is expected for Auth, Row Level Security, public/private profile separation, group membership, chat access, meetup permissions, RSVP capacity rules, and Realtime subscriptions.

Never commit service-role keys, production secrets, or private user/family data.
