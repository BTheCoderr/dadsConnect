# Contributing to DadConnect

DadConnect is a web + mobile community platform built with Next.js, Expo/React Native, TypeScript workspaces, and Supabase Auth/Postgres/RLS/Realtime.

Before a pull request, follow the README/setup instructions and run the existing CI checks. Changes to shared domain types, auth, RLS, groups, meetups, RSVPs, chat, profiles, or saved content should be checked across both web and mobile when applicable.

Preserve the separation between public community profile data and private family/location context.

A merged commit is not automatic approval for a production deployment.
